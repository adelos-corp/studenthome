# Studenthome

**One Home. Every Student.**

Studenthome is the connected student ecosystem by ADELOS Corp., bringing academic resources, institutions, exam schedules, results, learning links, scholarships, deadlines, documents, and student identity into one experience.

## Tech stack
- Next.js App Router
- React 19
- TypeScript
- CSS

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm start
```

## Deployment
The project is designed for Vercel. Import this repository into the existing Vercel project `studenthome-adeloscorp` and use the Next.js framework preset.

## Current splash-page interaction
- Porcelain white canvas with ADELOS blue HoloMosaic background
- Official ADELOS black logo in the header
- Small pointer radius and restrained pointer response
- Native HoloMosaic click-wave tile flip (`flipOnClick`)
